Add products, remove them, and adjust stock or prices — all without touching code.

How this works: this page edits a copy of your catalog in your browser only — it does not save to the live site by itself. When you're done making changes:
1. Click Download products.json below.
2. In your GitHub repo, replace the file at assets/data/products.json with the one you downloaded (upload it through github.com, or via git add / commit / push if you're comfortable with git).
3. Your live site updates within a minute or two of GitHub Pages rebuilding.

Heads up: this page has no password. Anyone with the link could open it and download a changed file — but since it can't publish anything on its own, that's low-risk for now. When you connect the real backend (see README.md → "Phase 2"), stock and pricing can update instantly and safely without this manual download/upload step.
